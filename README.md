# Legal & Compliance Command — Living Horizon

Private executive portal for the Head of Legal & Compliance.

Single-file web application. No build, no server, no dependencies.

- `index.html` — the entire application

## Access

The app is protected by an access code shown only to authorised staff.
All connection tokens (Gmail, Monday.com, AI) are entered at runtime and
stored only in the user's own browser — nothing sensitive is in this repository.

## Hosting

Served via GitHub Pages from the main branch root.
